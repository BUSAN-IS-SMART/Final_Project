### 전처리

- 부두·월별 자료 정리
  - 부두명과 기간을 맞춰 물동량·하역능력·입출항 자료 연결
  - 전체 가동률은 부두별 비율의 단순평균 대신 전체 물동량과 전체 하역능력으로 계산
  - 자료가 없는 연도의 시간 지표는 결측으로 유지
  - 재항시간과 작업시간은 자료 범위와 필터가 다르므로 별도 지표로 관리
- 터미널 작업시간 정제
  - 접안~출항(예정) 구간에서 중복 기록 제거
  - 2025년 부두 간 작업시간 비교에는 0시간 초과·120시간 미만 기준 적용
  - 해당 시간은 예정 시각을 포함할 수 있으므로 실제 순하역시간과 구분
- 신항 1부두 항차 연결
  - 선명 공백·대소문자 정규화 및 숫자 선석 일치 확인
  - 출항 시각 차이가 24시간 이내인 후보 중 최근접 기록을 일대일 연결
  - 원본 2,928건 중 2,884건 연결, 음수 대기 등 유효 시간 기준에 맞지 않는 69건 제외
  - 최종 2,815항차를 대기시간 분석 및 시뮬레이션에 사용

운영 지표 및 입출항 Case 정의

- 입항 → 접안(예정) → 선석 사용 → 출항(예정) → 기록상 출항으로 시간 구간 구분
- 관측 대기시간 : 접안(예정) 일시 − 입항 일시
- 선석 사용시간 : 출항(예정) 일시 − 접안(예정) 일시
- 재항시간 : 기록상 출항 일시 − 입항 일시
- 선석 점유율 : 분석 기간 내 점유시간 ÷ (선석 수 × 기간 시간) × 100
- 부두 가동률 : 실제 처리량 ÷ 동일 기간 하역능력 × 100
